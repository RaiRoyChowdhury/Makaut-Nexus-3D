# MAKAUT NEXUS 3D

**Futuristic 3D Gamified Academic OS & Placement Command Center for MAKAUT B.Tech IT Students**

Created by **Rai Roy Chowdhury** · Built with **Google Gemini (`@google/genai`)**, **React 19**, **Three.js**, **Express**, and **Firebase (Auth, Firestore, Storage)**.

---

## Overview

Engineering students often memorize university Previous Year Questions (PYQs) without visualizing how systems actually work—and freeze when translating plain-English algorithmic thinking into working code.

**MAKAUT NEXUS 3D** solves both problems in one interactive full-stack platform:
1. **Playable 3D Engineering Labs:** Turns core MAKAUT B.Tech IT Semester 3 subjects into tactile **Three.js** simulations with real-time **AI Hint Beams**, **AI Intuition**, and **Tutor Voice**.
2. **Photo-to-3D PYQ Lab Generator:** Upload a photo of any exam question (or click **Use Sample PYQ Photo**), speak it via mic/audio upload, or paste text—**Gemini Vision** extracts the concept and builds a custom playable 3D lab on the fly.
3. **Logic → Code Morph DSA Simulator:** Helps beginners bridge plain-English/voice/handwritten logic into **C, Python, C++, and Java**, featuring a **side-by-side Write Code** mode that checks student-written code clause-by-clause with clear reasoning.
4. **Full-Stack Cloud Sync & Guest-First UX:** Runs 100% immediately in **Guest Mode** (`localStorage`), with optional **Firebase Auth, Cloud Firestore (Student / Mentor / Admin RBAC), and Firebase Storage** for cross-device sync, PYQ photo history, cohort readiness, and Mentor-curated labs.

## Key Features

### 1. Exam Season — 6 Custom Three.js 3D Syllabus Labs (Sem 3)
* **`PCC-CS301` Unknot the Pointer 3D** *(Data Structures & Algorithms)* — Live 3D heap memory nodes, Floyd cycle breaking, node insertion, and list reversal.
* **`PCC-CS302` Ghost in the Fetch Cycle** *(Computer Organization & Architecture)* — 3D CPU pipeline stages (Fetch/Decode/Execute) and RAW hazard resolution.
* **`ESC-301` Laser Prism Logic** *(Analog & Digital Electronics)* — Dielectric mirrors and crystal logic gates (`AND`, `OR`, `NOT`, `NAND`, `XOR`) routing live 3D laser beams.
* **`BSC-301` Bridge of Kings** *(Mathematics-III)* — Stabilizing harmonic 3D bridges using ODEs, Laplace transforms, and eigenvalues.
* **`HSMC-301` Break-Even Horizon** *(Economics for Engineers)* — Interactive 3D cyber-factory tuning price, fixed/variable cost, and output volume.
* **`PCC-CS393` Stack-Frame Surgeon 3D** *(Python / IT Workshop Lab)* — Call-stack frame inspection, infinite recursion halting, and scope debugging.

### 2. Instant PYQ Lab Generator (Multimodal Gemini Vision + Voice)
* **Direct PYQ Photo Upload (`PNG` / `JPG` / `WEBP`):** Reads printed exam papers, screenshots, circuit diagrams, or handwritten questions using Gemini Vision.
* **1-Click Sample PYQ Photo:** Synthesizes a realistic `PCC-CS301` linked-list cycle exam paper PNG for instant live demos.
* **Voice & Audio Upload:** Dictate questions via microphone or upload audio notes across text inputs (`/api/ai/transcribe-audio`).

### 3. Placement Season Command Center
* **TSA Aptitude Gauntlet:** Timed quantitative/logical sprints dynamically generated by Gemini.
* **Interview Boss Duel:** 3-Shield technical interview arena with voice input and Gemini-scored feedback.
* **Capstone Project Forge + AegisGrid 3D:** Generates complete project blueprints alongside a 3D distributed Raft consensus cluster simulation.
* **DSA Logic → Code Morph Simulator:**
  * **English / Voice / Handwritten OCR** → synchronized clause-to-code mapping in **C, Python, C++, and Java** + 2D visual algorithm X-Ray.
  * **Write Code Mode:** Reference code & active-clause *"Why"* explanation on the left, live student code editor on the right, and **Check Logic & Reasons** evaluation via Gemini.

### 4. Full-Stack Firebase Auth, Firestore RBAC & Storage
* **Zero-Friction Guest Mode:** All 3D labs, PYQ Lab, Placement Season, and Judge Demo work immediately without sign-up.
* **Account Creation & Sign-In:** 1-click **Google Sign-In** and **Email/Password** registration with onboarding.
* **Role-Based Access Control (RBAC):**
  * **Student:** Syncs XP, level mastery, projects, DSA code reviews, and uploaded PYQ photo labs (`pyq-uploads/{uid}/...`).
  * **Mentor:** Publishes official curated PYQ 3D labs (`curated_pyqs`) with Firebase Storage image attachments for the whole cohort.
  * **Admin:** Reviews and approves/rejects `mentor_requests` with server-enforced Firestore rules.
* **PII Isolation:** Emails and roll numbers are isolated in `/users/{uid}/private/account`; public cohort leaderboards expose zero PII.

### 5. Judge Demo Readiness
* **Judge Demo Quick-Launch Drawer** in the top bar for instant navigation across core flows.
* **Downloadable 8-Page Technical Guidebook PDF** (`/MAKAUT_NEXUS_3D_Technical_Guidebook.pdf`).

## Architecture & Tech Stack

* **Frontend:** React 19, TypeScript, Vite 8, Tailwind CSS v4, Three.js, Lucide Icons, Motion
* **Backend:** Express (`server.ts`) serving 12 `/api/ai/*` endpoints + Vite middleware / static production build
* **AI Layer:** `@google/genai` with resilient dual-model routing (`gemini-3.1-flash-lite` primary → `gemini-4-hydrogen` fallback), structured JSON schemas, TTL response caching, cooldown handling, and deterministic local fallbacks
* **Cloud & Security:** Firebase Authentication, Cloud Firestore (`firestore.rules` audited with `@firebase/eslint-plugin-security-rules`), Firebase Storage (`storage.rules`)

### Backend AI Endpoints (`server.ts`)
| Endpoint | Purpose |
| :--- | :--- |
| `POST /api/ai/hint` | Context-aware 3D simulation hints |

| `POST /api/ai/transcribe-audio` | Voice/audio upload transcription for text fields |
| `POST /api/ai/aptitude-generate` | Dynamic MAKAUT placement aptitude questions |

| `POST /api/ai/interview-eval` | Multi-rubric interview answer evaluation |
| `POST /api/ai/project-forge` | Structured capstone blueprint generator |

| `POST /api/ai/logic-ocr` | Handwritten notes / code screenshot OCR |
| `POST /api/ai/logic-code-review` | Side-by-side student DSA code vs. logic-clause reviewer |

## Getting Started

### Prerequisites
* Node.js 20+
* A Gemini API key (`GEMINI_API_KEY`)

### Installation & Local Development
```bash
# 1. Install dependencies
npm install

# 2. Configure environment variables (copy .env.example to .env)
# Set GEMINI_API_KEY="your_api_key_here"

# 3. Start full-stack dev server (Express + Vite on port 3000)
npm run dev
```

### Build & Verification Commands
```bash
# Type-check TypeScript
npm run lint

# Build production frontend bundle
npm run build

# Lint Firestore security rules
npx eslint firestore.rules
```
